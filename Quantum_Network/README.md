# Quantum Networks

This folder contains my quantum network simulations using Python, NetQASM and NetSquid.

The simulations are mainly from the *Quantum Computer and Quantum Internet Applications: Hands-on Training with QuTech's Quantum Demonstrators* course and are part of my Personal Quantum Lab.

The main goal is to study quantum communication protocols and how different quantum nodes can communicate with each other using quantum and classical channels. This includes concepts such as entanglement generation, EPR pairs, quantum teleportation, quantum measurements and quantum state fidelity.

Some of the applications were cloned from the Quantum Network Explorer (QNE) using their clone function. These applications are used to understand how the corresponding protocols work and how they can be simulated within a quantum network.

## Tools

- Python
- Quantum Network Explorer (QNE)
- QNE Application Development Kit (QNE-ADK)
- NetQASM
- SquidASM
- NetSquid
